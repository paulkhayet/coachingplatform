# OAuth button assets

- `google-signin-light.png` is Google's pre-approved Android + Web neutral rectangular button from the official Sign in with Google asset bundle. This approved variant has no outline.
- `apple-continue-white.png` is generated by Apple's official Sign in with Apple button endpoint with a white background, no border, `continue` label, 180 × 40 point size, 4 point corner radius, and 4× scale.

Do not redraw, recolor, crop, or change the aspect ratio of these files. Replace them only with updated provider-approved assets.
