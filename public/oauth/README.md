# OAuth button assets

- `google-signin-light.png` is Google's pre-approved Android + Web light rectangular button from the official Sign in with Google asset bundle.
- `apple-continue-white.png` is generated by Apple's official Sign in with Apple button endpoint with a white background, border, `continue` label, 180 × 40 point size, 4 point corner radius, and 4× scale.

Do not redraw, recolor, crop, or change the aspect ratio of these files. Replace them only with updated provider-approved assets.
